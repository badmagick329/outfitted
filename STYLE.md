# Outfitted interface style

Build a private, image-led wardrobe tool—not a generic AI SaaS product or a retail landing page.

- Use a charcoal/ink base, off-white text, and lime as the single confident accent. Define colour through CSS variables.
- Use IBM Plex Sans with IBM Plex Mono for compact metadata. Keep hierarchy strong, density practical, and borders subtle.
- Garment images are the primary visual material. Use cards only for meaningful grouping; avoid nested cards, glass effects, gradients, giant pills, emoji, and stock dashboard widgets.
- Prefer compact controls, clear states, tables/lists when appropriate, and quiet background atmosphere. Motion is limited to fast hover/focus feedback.
- Mobile upload must be effortless; desktop inventory browsing should feel like a calm, capable personal tool.
- Before considering a UI complete, check: coherence, distinctiveness, typography/spacing/contrast craft, and whether a user can complete the primary action without guessing.
